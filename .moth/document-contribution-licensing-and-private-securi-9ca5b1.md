The public repository has no project license, contribution guide or dedicated security-reporting instructions.

Acceptance criteria:

- Have the owners select an explicit project license and add it.
- Document setup, validation, contribution expectations and Moth usage.
- Provide a private channel for vulnerability reports without inviting secrets or exploit details into public tickets.
- Explain that external contributions are reviewed and cannot deploy automatically.
- Keep documentation focused on ongoing project use.
